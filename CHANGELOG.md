# Історія змін

## [1.0.0] — 2026-11-01

### Звірка з оригінальним гайдом, 01.11.2026

- Додано компоненти трасування, видиму UML, версії перевіреного середовища.
- Уточнено проєктний API й 15 модульних специфікацій; виконання UT не заявлено.
- Додано оцінки ітерації, WBS/SP/Gantt, ілюстровану інструкцію й правила супроводу.
- Зафіксовано 15 реальних статичних зауважень окремо від людських PR-коментарів.
- Прибрано хибну вимогу 10 GitHub-коментарів; обсяги гайду й додаткові матеріали розмежовано.
- Додано поточні PNG порожнього пошуку, порожнього RSS і помилки новин.

Навчальний випуск документації, не сертифікація поведінки застосунку.
Дати попередніх ручних перевірок і версія застосунку не вигадуються.
Історія Git є джерелом фактичних дат комітів.

### Підготовлені матеріали

- Бачення, SRS, межі MVP, процес, план ітерації та трасування.
- Сценарії, архітектура, модулі, API, план інтеграції та три ADR.
- Проєктна модель даних і правила валідації.
- Матеріали прототипу з частковими ручними спостереженнями.
- План перевірок, 31 функціональний тест-кейс, 6 нефункціональних перевірок.
- Попередній звіт, основа звіту про рев’ю та BUG-001.
- План роботи, ризики, план випуску та інструкція користувача.

### Зміни цього пакета

- Документи управління перенесено з помилково вкладеної
  `3-implementation/5-management/` до кореневої `5-management/`.
- Додано порядок супроводу, навігацію README та перевірки документації.
- Оновлено статуси доданих матеріалів прототипу й посилання трасування.
- Виправлено окрему мовну неточність у тест-кейсах.

### Виправлення та перевірка BUG-001

- Додано патч порожнього стану пошуку й докази ізольованої перевірки.
- 29 методів unittest повторно пройшли; повний канонічний прогін не виконано.
- [Користувацьке підтвердження](4-quality/bugreports/BUG-001-search-empty.md)
  збережено окремо від початкового провалу TC-05.

### Завершення технічного узгодження комплекту

- PR №2 з Excel-шаблоном та PR №4 з виправленнями злиті в main.
- Додано архів застосунку без БД, патч BUG-002–004, 41/41 методів unittest і 15/15 допоміжних браузерних сценаріїв; початкові невдачі збережені.
- Користувач надав скриншот запуску нового інтерфейсу; це не повтор усіх тестів на його ПК.
- Опрацьовано фактичні коментарі Михайла й Дмитра; узгоджено README, план, трасування, супровід та статуси дефектів.
- Excel залишається шаблоном, не підміняє історичні результати; нові перевірки не оголошено 37/37 канонічними TC/QT.

### Відомі обмеження

- Повний формальний прогін, зовнішнє дослідження потреб і людський перегляд нової копії не завершені.
- Ринковий поріг UI цієї копії 60 с потребує командного погодження; дослідницький захист 35 с не послаблено.
- Нові повідомлення UA/EN, інші мови мають EN fallback; доступність зовнішніх джерел не гарантована.
- Відомо 4 фактичні дефекти; додаткові дефекти або коментарі рев’ю не вигадуються для кількісних вимог.
- Теги оформлюються поточним рішенням Івана як консолідовані знімки, без вигаданих старих дат; погодження викладача не підміняється технічною перевіркою.

### Git-вправа та публікація

- Реальний конфлікт паралельних уточнень README розв’язано вручну через Accept both changes,
  Mark as resolved і Commit merge; merge рішення `3a1f01d`, докази у Git-звіті.
- Фінальний стан інтеграції й CI — у PR №6 та Actions; Release позначає точний commit.
