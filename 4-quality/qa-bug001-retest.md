## Зміна

За відсутності збігів у завантаженому списку показується «Нічого не знайдено» та підказка «Змініть або очистіть пошуковий запит».
Блок має `role="status"` і `aria-live="polite"`. Доступність зі скринрідером окремо не перевірялася.
За зміни або очищення запиту повідомлення зникає. Початковий стан завантаження не підмінено результатом пошуку.

## Повторна перевірка

Середовище: локальні Flask/Chromium, окрема тимчасова SQLite, контрольовані демонстраційні котирування; без реальних угод і без робочої БД користувача.

| Перевірка | Результат |
|---|---|
| `wwww` на ширинах 390 і 1440 px | 0 карток і видиме повідомлення; TC-05 пройдено для виправленої копії |
| Збереження повідомлення після циклу опитування | Пройдено на обох ширинах |
| BTC / btc / Bitcoin / bitcoin | Одна картка Bitcoin, без порожнього повідомлення; TC-03 пройдено |
| Зміна запиту на BTC | Повідомлення зникає, картка повертається |
| Очищення та пробіли | 15 карток; TC-04 пройдено |
| Початковий запит цін примусово повертає HTTP 503 | Зберігається skeleton, повідомлення про відсутність збігів не показано. Це не підтвердження повноти UX помилки |
| JavaScript pageerror у пошуковому сценарії | 0 |
| Наявні unittest | 8 + 14 методів, усі пройдено |
| Додаткові незалежні unittest | 7 методів, усі пройдено |

Разом повторно пройшли **29 методів unittest** та браузерні сценарії. Це не 29 канонічних тест-кейсів Excel і не повний прогін усіх вимог.
